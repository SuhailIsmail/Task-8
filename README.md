# 🛍️ Sales Dashboard Project

This Power BI project showcases a simple interactive sales dashboard using the **Online Retail dataset**. The dashboard visualizes sales performance by **product**, **region**, and **month**, offering key insights for business users.

---

## 📈 Dashboard Features

- 📊 **Line Chart:** Sales trend over Month-Year
- 🗂 **Bar Chart:** Total sales by Country
- 🍩 **Donut Chart:** Sales by Top-Selling Products
- 🔍 **Slicer Filter:** Country-level drill down
- 🎨 **Conditional Formatting:** Highlights top-performing regions and products using color coding

---

## 🧠 Key Insights

1. **United Kingdom** contributes over **80% of total revenue** – the primary sales market.
2. **Sales peaked in November 2011**, likely due to holiday season promotions.
3. Countries like **Germany, France, and Netherlands** show consistent monthly sales.
